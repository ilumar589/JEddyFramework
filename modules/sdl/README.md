# jeddy-sdl

Module `dev.jeddy.sdl`. Raw SDL3 and SDL3_mixer bindings generated by jextract, plus low-level helpers. Exported only to engine modules; games use `window`, `input` and `audio`.

## Key types

- `dev.jeddy.sdl.ffi`, `dev.jeddy.sdl.mixer.ffi`: generated bindings (regenerate with `./gradlew :sdl:regenerateBindings`)
- `Sdl`: native loading and error checks

## Threading

SDL's rules apply: video, events and windows on the main thread.
